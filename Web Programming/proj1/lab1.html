Lab Activity: Hands-On 1 and Hands-On 2

CS-44105-001 - Web Programming I - Fall 2026

Hands-On 1: HTML Basics and Images

Hands-On 1 focused on the fundamentals of writing an HTML5 document from scratch: setting up the basic document structure (the doctype declaration, the html element, the head element, and the body element), adding headings and paragraphs, and correctly inserting images with the img element. Particular attention was paid to using proper alt and title attributes on every image, since alt text is essential for accessibility and for describing an image when it cannot be displayed.

Hands-On 2: Lists, Navigation, and Validation

Hands-On 2 built on those basics by introducing lists (ordered and unordered) as a way to structure grouped content, and the semantic nav element as the proper way to mark up a site's navigation menu, exactly the pattern used for the menu at the top of every page in this project. The activity closed with an introduction to HTML validation: using a validator to check that a page's markup is well-formed and standards-compliant before it is considered finished.

Together, these two Hands-On activities cover the core skills this project relies on: writing valid HTML5 by hand, structuring pages with semantic elements, embedding properly-described images, and confirming correctness with a validator.
