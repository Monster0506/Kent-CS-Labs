Lecture 5: URLs, HTTP, Web Browsers, and Web Servers

CS-44105-001 - Web Programming I - Fall 2026

Building on Lecture 4, Lecture 5 revisited URLs and explained how they are used in practice to request specific resources from a web server, then focused on HTTP (HyperText Transfer Protocol), the protocol browsers and servers use to communicate over the Internet.

We walked through the request-response cycle: a web browser (the client) sends an HTTP request to a server, specifying a method such as GET (retrieve a resource) or POST (submit data). The web server processes that request and sends back an HTTP response, which includes a status code (like 200 OK or 404 Not Found) and, usually, the requested content.

Finally, the lecture emphasized the complementary roles of browsers and servers: the browser is responsible for requesting, receiving, and rendering content for the user, while the server is responsible for storing resources and responding correctly to incoming requests. This request-response relationship is the backbone of how every website on the Internet works.
