# Fruit Processing: Container Adapters, Multimaps, STL Algorithms

## Lab Assignment

 The project contains four parts: 
1.   **Lemons (container adapters)** Recode [lemon picking](http://antares.cs.kent.edu/~mikhail/classes/cs3/Labs/Lab6/lemons.cpp) example to use the priority queue container adapter instead of a hand-written loop. 
2.   **Oranges (multimaps, emplace)** Recode [orange selection](http://antares.cs.kent.edu/~mikhail/classes/cs3/Labs/Lab6/oranges.cpp) example such that it uses a multimap instead of vector to store fruit as well as upper_bound(), lower_bound() functions and emplace() to populate the multimap. 

3.   **Apples (algorithms I)** Recode [apple sorting](http://antares.cs.kent.edu/~mikhail/classes/cs3/Labs/Lab6/apples.cpp) examples such that they use suggested STL algorithms instead of hand-written loops. 
4.   **Peaches (algorithms II)** Recode [peach jamming](http://antares.cs.kent.edu/~mikhail/classes/cs3/Labs/Lab6/peaches.cpp) example to use suggested STL algorithms instead of hand-written loops. 

**Milestone:** Implement the first assignment.

**Hint:** Refer to [this example](http://antares.cs.kent.edu/~mikhail/classes/cs3/Examples/STLContainersSequential/Vectors/priorityQueue.cpp) for priority queue usage.
